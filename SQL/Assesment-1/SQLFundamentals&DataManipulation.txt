SQL ASSESSMENT 1
SQL Fundamentals & Data Manipulation

Q1. Which data type is most appropriate for storing currency values to avoid floating-point errors?

Answer:
DECIMAL(10,2)


Q2. Which constraint ensures that every student has an email address, while allowing duplicate email addresses?

Answer:
NOT NULL


Q3. Which SQL operator is used to filter records where department_id is 1, 3, or 5?

Answer:
IN

Example:
WHERE department_id IN (1, 3, 5);


Q4. How would you find students whose last_name starts with the letter 'S'?

Answer:
WHERE last_name LIKE 'S%';


Q5. Why does the following query return zero rows?

SELECT * FROM students
WHERE email = NULL;

Answer:
NULL cannot be compared using =.
Use IS NULL instead.

Correct query:
SELECT * FROM students
WHERE email IS NULL;
